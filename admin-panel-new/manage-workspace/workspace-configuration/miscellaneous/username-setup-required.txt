1.
Title: Should username setup required

Steps:
# Log in to the workspace as Workspace Admin
# Go to Manage Workspace > Workspace Info page
# Click on the "Miscellaneous" tab
# Check the "Username Setup Required" checkbox
# Click on the Save button

Expectation:
Success alert will be shown

Steps:
# Go to the profile page
# Click on the "Settings" tab

Expectation:
"Username" field will not be available

2.
Title: Should username setup not required

Steps:
# Log in to the workspace as Workspace Admin
# Go to Manage Workspace > Workspace Info page
# Click on the "Miscellaneous" tab
# Uncheck the "Username Setup Required" checkbox
# Click on the Save button

Expectation:
Success alert will be shown

Steps:
# Go to the profile page
# Click on the "Settings" tab

Expectation:
"Username" field will be available

3.
Title: Should cancel toggling the checkbox

Steps:
# Log in to the workspace as Workspace Admin
# Go to Manage Workspace > Workspace Info page
# Click on the "Miscellaneous" tab
# Toggle the "Username Setup Required" checkbox
# Click on the Cancel button

Expectation:
No success alert will be shown
The state of the checkbox will remain as it was
